Settings & Data

Privacy

Your data is stored locally on this device. This application does not send inventory data to a server and contains no analytics or telemetry.

Clearing browser/app storage can permanently remove local data. Keep regular JSON backups.

Data tools

Offline / PWA

When served from HTTPS or localhost, the service worker caches the application shell for offline loading. Install it from the browser's Add to Home Screen / Install App action.

XLSX export is implemented with a dependency-free local ZIP/XLSX writer fallback so export remains functional offline. The app can also use a vendored SheetJS build if you add xlsx.full.min.js beside this file.

Packaging

Run locally with any static server. Deploy the folder to GitHub Pages or another static host. The same web app can later be wrapped with Capacitor; iOS distribution requires Apple's signing/provisioning process.
